### 7.7 CLI/CI için API anahtarı (F1'de yalnız API ile)

Arayüzde anahtar ekranı yok (D-22). Anahtar yalnız oturum çereziyle ve
aynı-origin `Origin` başlığıyla üretilir. Git Bash örneği:

```sh
read -rs OSSR_PW
curl -s -c ossr-cookie.txt -H "Origin: http://127.0.0.1:3001" -H "Content-Type: application/json" \
  --data "{\"password\":\"$OSSR_PW\"}" http://127.0.0.1:3001/api/auth/login
curl -s -b ossr-cookie.txt -H "Origin: http://127.0.0.1:3001" -H "Content-Type: application/json" \
  --data '{"name":"ci"}' http://127.0.0.1:3001/api/auth/api-keys
rm ossr-cookie.txt; unset OSSR_PW
```

Yanıttaki `key` değeri yalnız bir kez gösterilir. İsteklerde
`Authorization: Bearer <anahtar>` kullanılır. Yeni anahtar öncekini otomatik
iptal eder; iptal: `DELETE /api/auth/api-keys/{id}` (yine çerezle). Çerez
dosyası oturum token'ı içerir, işiniz bitince silin. Parolada `"` veya `\`
varsa JSON gövdesini buna göre kaçışlayın.
