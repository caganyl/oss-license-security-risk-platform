Özellikler

Yeni proje taraması

Yeni bir proje oluşturun: kodunu (repo veya yerel klasör), çalışan web adresini ya da ikisini birden tarayın.

Yerel klasör, sunucuda SCAN_ROOTS ile izin verilen bir kökün altında olmalı. https adresi Azure DevOps / TFS, GitHub veya GitLab reposu olabilir; dal belirtilmezse reponun varsayılan dalı taranır.
Özel (giriş isteyen) repolar için gerekir. Azure DevOps / TFS'te: sağ üstte kullanıcı menüsü → Personal access tokens → New Token, kapsam olarak yalnız Code → Read yeterli. Token şifreli saklanır, ekranda tekrar gösterilmez. Şirket sunucusu Windows oturumunu kabul ediyorsa yönetici GIT_WINDOWS_AUTH_HOSTS ile tokensız erişimi de açabilir.
Çalışan uygulamanın adresi; pasif web taraması yapılır. Yalnız WEB_SCAN_ALLOWED_HOSTS listesindeki (kendi/şirket) sistemler taranabilir.
Teknoloji (ekosistem)
Boş bırakılırsa tüm desteklenen ekosistemler otomatik algılanır (önerilen). Kilit dosyası (lock) olan projeler en doğru sonucu verir; yalnız pom.xml, build.gradle, composer.json veya Cargo.toml varsa dolaylı paketler görünmez.

Web taraması hedefi

Çalışan uygulamanın adresini girin.

Boş bırakılırsa web adresi kaldırılır.
Aktif tarama yalnız OWASP ZAP tanımlıysa çalışır ve sisteme gerçek saldırı istekleri gönderir; kayıt/veri oluşturabilir. Canlı sistemlerde değil, test ortamında kullanın.

Repo erişim anahtarı

Özel bir repo için erişim anahtarı.

Azure DevOps / TFS'te: kullanıcı menüsü → Personal access tokens → New Token, kapsam Code → Read. Yeni token kaydetmek eskisinin yerine geçer. Token yalnız bu repo sunucusuna gönderilir ve ekranda tekrar gösterilmez.
